# Quick Start Guide

## 🚀 Get Running in 30 Seconds

### 1. Start the Server
```bash
npm run dev
```

### 2. Open Your Browser
Navigate to: **http://localhost:5500**

### 3. Start Exploring!
- Select a neurotransmitter from the dropdown
- Click "Release Neurotransmitters"
- Watch the magic happen!

---

## 🎮 Basic Controls

### Mouse
- **Left Click + Drag** - Rotate camera
- **Right Click + Drag** - Pan camera
- **Scroll Wheel** - Zoom in/out

### Buttons
- **Release Neurotransmitters** - Send particles across synapse
- **Toggle Reuptake Inhibition** - Turn off/on clearance (simulates drugs)
- **Reset** - Clear everything and start fresh

### Dropdown
- Select which neurotransmitter type to release

---

## 👀 What to Look For

### First Release
1. **Axon terminal pulses** (left side)
2. **Colored spheres appear** and pop into view
3. **Particles drift rightward** across the blue cleft
4. **Receptors light up** red or green when particles bind
5. **Emotional face reacts** (top-right corner)

### After a Few Seconds
- Some particles **bind to receptors** (stick and glow)
- Others **get pulled into orange transporters** (reuptake)
- Some **break apart near red enzymes** (degradation)
- Bound particles eventually **unbind and drift away**

### Try This
1. Release **Dopamine** (purple) - Watch for red receptors
2. Click **"Toggle Reuptake Inhibition"** - Button turns red
3. Release **Dopamine** again - Particles last much longer!
4. Click **Reset** - Everything clears

## 🎨 Color Guide

### Neurotransmitters
- 🟣 Purple = **Dopamine** (reward)
- 🟠 Orange = **Serotonin** (mood)
- 🔵 Blue = **Glutamate** (excitatory)
- 🟢 Green = **GABA** (inhibitory)
- 🔴 Red = **Norepinephrine** (arousal)

### Receptors
- Gray = **Inactive** (waiting)
- Red = **Bound (excitatory)**
- Green = **Bound (inhibitory)**

### Transporters
- Orange = **Active** (working)
- Red = **Inhibited** (blocked)

## 🎯 Quick Experiments

### Experiment 1: Compare Types (2 min)
1. Release Dopamine → Observe
2. Reset
3. Release GABA → Compare behavior
4. Notice: Different colors, speeds, receptor colors

### Experiment 2: Drug Effects (2 min)
1. Release Serotonin normally
2. Count how long particles last (~10 sec)
3. Reset
4. Toggle Reuptake Inhibition ON
5. Release Serotonin again
6. Count again (~60+ sec!)
7. This is how antidepressants work!

### Experiment 3: Receptor Saturation (2 min)
1. Click Release 5 times rapidly
2. Watch receptors fill up
3. Notice new particles can't bind
4. Wait for unbinding
5. See receptors become available again

## ⚡ Performance Tips

- **Smooth:** 1-2 releases at a time
- **Busy:** 3-4 releases (lots of action)
- **Laggy?** Reset and reduce releases

---

## 🐛 Troubleshooting

### Nothing appears?
- Check browser console (F12) for errors
- Make sure you're using a modern browser
- Try refreshing the page

### Slow performance?
- Close other browser tabs
- Reset the simulation
- Reduce number of simultaneous releases

### Can't rotate camera?
- Make sure you're clicking on the 3D view (not UI)
- Try right-click drag instead
